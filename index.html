⚡ Root Cause Breakdown

1-Sec Cutout: Elgato Wave Link holds exclusive hardware ownership of Elgato Wave:3. Direct output triggers CoreAudio AudioQueueStart (-66681) error, terminating playback after buffer fill.

10-Sec Cutout: USB microframe clock drift in usbaudiod (3,307 CPU mins uptime) and stale browser audio contexts trigger libAudioIssueDetector (-120 dB silence).

💻 Workstation CLI Quickstart

Run these commands from the audio-settings terminal directory on the Mac mini: 

# Apply verified stable settings (Scarlett out + Wave Link in)
./audio.sh fix

# Verify continuous 6-second audio playback
./audio.sh test-output --continuous

# Refresh stale browser audio contexts if audio drops
./audio.sh fix-browser

# Full hardware and sample rate audit
./audio.sh doctor

⚠️ Still experiencing audio drops after 10 seconds?

1. USB Hub Power: Plug the Scarlett 2i2 directly into the rear USB port of the Mac mini instead of a hub or dock.
2. Reset CoreAudio & usbaudiod: Run sudo killall coreaudiod in terminal to clear USB clock drift.
3. Refresh Browser Service: Run ./audio.sh fix-browser to cleanly rebind Chrome's audio context.
